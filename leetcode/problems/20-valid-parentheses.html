Valid Parentheses
Easy Bracket Matching Stack
Problem Statement

Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

An input string is valid if:

  • Open brackets must be closed by the same type of brackets.
  • Open brackets must be closed in the correct order.
  • Every close bracket has a corresponding open bracket of the same type.
EXAMPLES
s = "()" → true
s = "()[]{}" → true
s = "(]" → false
s = "([)]" → false
s = "{[]}" → true

Stage 3 — Approach Discussion
Me
Candidate
Let me think through this. The core challenge is that a closing bracket must match the most recent unmatched opening bracket. That "most recent" constraint is the classic signature of a stack — LIFO gives us exactly that ordering.
My plan: iterate through the string. Push every opening bracket. When I see a closing bracket, pop the stack and check if they form a valid pair. If the pop result doesn't match, return false immediately. At the end, the stack must be empty (no unmatched openers left).
Me
Candidate
My approach: use a stack and a hash map that maps each closing bracket to its expected opening bracket. For each character:

— If it's an opening bracket, push it.
— If it's a closing bracket, pop the stack (or use a sentinel if empty) and check it matches the map.
— At the end, return whether the stack is empty.

This handles all three invalidity cases: wrong type, wrong order, and unmatched openers. Does that sound like a good direction?
IV
Interviewer

Stage 4 — Pseudocode Walkthrough
Me
Candidate
Let me walk through the pseudocode first before writing the actual code:
Pseudocode
function isValid(s):
    stack = []
    pairs = { ')': '(',  ']': '[',  '}': '{' }

    for ch in s:
        if ch in pairs:                    # it's a closing bracket
            top = stack.pop() if stack else '#'   # sentinel for empty stack
            if pairs[ch] != top:
                return False            # mismatch → invalid
        else:
            stack.append(ch)           # opening bracket → push

    return len(stack) == 0             # must be fully matched
Me
Candidate
Let me trace through "{[]}" to verify:

'{' → push. Stack: [ '{' ]
'[' → push. Stack: [ '{', '[' ]
']' → closing. Pop → '['. pairs[']'] = '[' ✓
'}' → closing. Pop → '{'. pairs['}'] = '{' ✓
Stack empty → return true ✅
IV
Interviewer
Good trace. Now what about the edge case "([)]"?
Me
Candidate
'(' → push. Stack: [ '(' ]
'[' → push. Stack: [ '(', '[' ]
')' → closing. Pop → '['. But pairs[')'] = '(' ≠ '[' → return false ✅

The interleaving is caught immediately because the stack top doesn't match.

Me
Candidate
Time: O(n) — single pass through the string, each character is pushed/popped at most once.

Space: O(n) — worst case the stack holds n/2 opening brackets (e.g. "(((((").

This is optimal — we must read every character at least once, so O(n) time is a lower bound.

Stage 6 — Follow-up Questions
IV
Interviewer
Two follow-ups: (1) Can you handle it without a hash map? (2) What if we also needed to support custom bracket pairs like <>?
Me
Candidate
(1) Without a hash map: Instead of storing opening brackets in the stack, we can push the expected closing bracket when we see an opener. Then for each closing bracket we just compare it to the stack top directly — no map needed.

(2) Custom pairs: The algorithm is already data-driven — just pass in the pairs dictionary as a parameter instead of hardcoding it. Any set of bracket pairs works as long as each opener maps to exactly one closer.
IV
Interviewer
Nice. One more — what's the minimum length for a valid non-empty string?
Me
Candidate
Length 2 — a single open-close pair like "()". Any odd-length string is automatically invalid since brackets must come in pairs — we can short-circuit and return false for odd len(s) as a micro-optimisation.

✅ Full Python Solution

Python 3 — Valid Parentheses O(n) time · O(n) space 
class Solution:
    def isValid(self, s: str) -> bool:
        if len(s) % 2 != 0:          # odd length → always invalid
            return False

        pairs = {')': '(', ']': '[', '}': '{'}
        stack = []

        for ch in s:
            if ch in pairs:
                top = stack.pop() if stack else '#'
                if pairs[ch] != top:
                    return False
            else:
                stack.append(ch)

        return not stack
Key Interview Tips 面试要点
  • Always handle the empty stack case before popping — use a sentinel like '#'
  • The map keys are closing brackets (easier to look up on arrival)
  • Final check is not stack, not just return True — unmatched openers must be caught
  • Mention the odd-length short circuit — shows attention to optimisation
