📚 Stack

A LIFO (Last In, First Out) data structure — essential for matching, history tracking, and "next greater" problems.
栈 — 后进先出，面试高频数据结构

Core Idea 核心思路
Think of a stack as a pile of plates — you always add to and remove from the top. The key insight: whatever you pushed last is the first thing you'll process next. In Python, a plain list is a perfect stack.

Core Operations

Python
stack = []

stack.append(1)   # push  →  [1]
stack.append(2)   # push  →  [1, 2]
stack.append(3)   # push  →  [1, 2, 3]

top = stack[-1]   # peek  →  3  (no remove)
val = stack.pop() # pop   →  val=3, stack=[1,2]

bool(stack)        # isEmpty check → True if non-empty

All operations are O(1) time, O(n) space.

Pattern 1 — Bracket / Pair Matching

Trigger Keywords 触发关键词
"valid parentheses", "balanced brackets", "matching tags", "valid string" — any problem where you need to confirm opening/closing elements pair up correctly.

Core Template

Pseudocode — Bracket Matching
function isValid(s):
    stack = []
    pairs = { ')': '(', '}': '{', ']': '[' }

    for ch in s:
        if ch in pairs:            # closing bracket
            top = stack.pop() if stack else '#'
            if pairs[ch] != top:
                return False
        else:                        # opening bracket → push
            stack.append(ch)

    return len(stack) == 0       # stack must be empty at end

Pattern 2 — Monotonic Stack

Trigger Keywords 触发关键词
"next greater element", "previous smaller", "daily temperatures", "largest rectangle", "stock span" — any problem asking for the nearest element larger/smaller than the current one.
Core Insight 核心思路
Maintain a stack of indices whose corresponding values are in decreasing order. When nums[i] > nums[stack.top()], the current element is the "next greater" answer for the element at the top — pop and record it. Repeat until the stack is monotone again.

Core Template

Pseudocode — Monotonic Stack (Next Greater)
function nextGreater(nums):
    n      = len(nums)
    result = [-1] * n       # default: no greater element
    stack  = []               # stores INDICES (not values)

    for i in range(n):
        # while stack top's value is smaller than current
        while stack and nums[i] > nums[stack[-1]]:
            idx = stack.pop()
            result[idx] = nums[i]   # current is the answer for idx
        stack.append(i)

    return result

Pattern 3 — Stack + Auxiliary Info (Min Stack)

Trigger Keywords 触发关键词
"design a stack that supports getMin in O(1)", "constant time minimum" — the key constraint is that pop() must not break the min retrieval.
Core Insight 核心思路
Keep a second min-stack that mirrors the main stack. Each entry in the min-stack stores the minimum value seen so far at that depth. When you pop the main stack, also pop the min-stack — the invariant is always maintained.
Pseudocode — Min Stack
class MinStack:
    def __init__(self):
        self.stack     = []   # main stack
        self.min_stack = []   # parallel min-tracking stack

    def push(self, val):
        self.stack.append(val)
        cur_min = min(val, self.min_stack[-1] if self.min_stack else val)
        self.min_stack.append(cur_min)

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()   # always pop both together

    def getMin(self) -> int:
        return self.min_stack[-1]   # O(1) — top of min-stack

Pattern 4 — Expression Evaluation

Trigger Keywords 触发关键词
"evaluate expression", "basic calculator", "reverse polish notation", "postfix", "decode string", "nested" — any problem involving operators, operands, and/or parentheses that must be resolved in the correct order. （含运算符、括号或嵌套结构时，考虑用栈保存中间状态）
Core Insight 核心思路

Both flavours share one key idea: the stack saves "outer context" while you resolve "inner content".

  • Postfix / RPN — operands go on the stack; an operator pops two, computes, pushes the result back.
  • Infix + parentheses — on (, push the running result and current sign (pausing the outer expression); on ), pop and merge back into the outer result.

括号 = "暂存外层状态，先算内层"

Template A — Reverse Polish Notation (Postfix)

Pseudocode — RPN Evaluator (LC #150)
function evalRPN(tokens):
    stack = []
    for token in tokens:
        if token not in {'+','-','*','/'}:
            stack.append(int(token))       # operand → push
        else:
            b = stack.pop()                 # right operand (popped first!)
            a = stack.pop()                 # left operand
            if   token == '+': stack.append(a + b)
            elif token == '-': stack.append(a - b)
            elif token == '*': stack.append(a * b)
            elif token == '/': stack.append(int(a / b))  # truncate toward zero
    return stack[0]
RPN Trace — ["2","1","+","3","*"] → 9
"2" → push           stack: [2]
"1" → push           stack: [2, 1]
"+" → pop 1,2 → 2+1=3, push   stack: [3]
"3" → push           stack: [3, 3]
"*" → pop 3,3 → 3×3=9, push   stack: [9]
return stack[0] = 9 ✓

Template B — Basic Calculator (Infix + Parentheses)

Pseudocode — Basic Calculator (LC #224)
function calculate(s):
    stack  = []    # saves (outer_result, sign_before_paren) pairs
    result = 0
    num    = 0
    sign   = 1    # +1 or -1

    for ch in s:
        if ch.isdigit():
            num = num * 10 + int(ch)      # accumulate multi-digit number
        elif ch == '+':
            result += sign * num; num = 0; sign = 1
        elif ch == '-':
            result += sign * num; num = 0; sign = -1
        elif ch == '(':
            stack.append(result)          # freeze outer result
            stack.append(sign)            # freeze sign in front of '('
            result = 0; sign = 1          # fresh slate for inner expression
        elif ch == ')':
            result += sign * num; num = 0
            result *= stack.pop()          # apply sign before '('
            result += stack.pop()          # restore outer result

    return result + sign * num           # flush last number
Infix Trace — "1 + (2 - 3)" → 0
'1' → num=1
'+' → result=1, num=0, sign=+1
'(' → push result=1, push sign=+1   stack:[1,+1]   result=0, sign=+1
'2' → num=2
'-' → result=2, num=0, sign=−1
'3' → num=3
')' → result += −1×3 = −1   pop sign(+1): result=−1   pop outer(1): result=0
return result + sign×num = 0 ✓
Complexity 复杂度
Both templates: O(n) time — each token/character visited once. O(n) space — stack depth bounded by nesting level.
